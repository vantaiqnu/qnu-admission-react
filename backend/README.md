# Backend boundary

Backend chưa chạy trong phiên bản hiện tại. Thư mục này là ranh giới dành cho giai đoạn tiếp theo:

- API xác thực và tiếp nhận hồ sơ.
- Kiểm tra định dạng, kích thước và quyền truy cập file.
- OCR server-side và chuẩn hóa kết quả.
- Lưu file/kết quả vào storage và database.

Các request và response dự kiến được định nghĩa trong thư mục `../contracts/`. Frontend hiện chạy OCR local trong trình duyệt, vì vậy không cần khởi động backend để chạy bản demo.
